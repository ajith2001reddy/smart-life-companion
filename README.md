# 🌟 Smart Life Companion

> Your All-in-One AI-Powered Health, Fitness, and Lifestyle Ecosystem.

Smart Life Companion is a high-fidelity, full-stack application designed to revolutionize personal wellness. By integrating real-time health biometrics, advanced AI coaching, and intelligent data analysis, it provides users with a personalized roadmap to their best selves.

---

## ✨ Key Features

### 🤖 AI Health Coach
*   **Context-Aware Intelligence**: Personalized coaching based on your real-time health data (Steps, HR, Sleep patterns).
*   **Conversational Interface**: Natural language interactions powered by **GPT-4o mini**.

### 🍎 Smart Nutrition & Vision
*   **AI Food Scanner**: Upload a photo of your meal and let the AI estimate calories, protein, carbs, and fats instantly.
*   **Nutrition Tracking**: Automatically log meals and maintain a daily nutritional balance.

### 🏋️ Dynamic Workout Architect
*   **Smart & Pro Plans**: Generate custom workout regimens based on your goals (Fat Loss, Muscle Gain, Maintenance) and BMI.
*   **AI generation**: Pro mode utilizes deep learning to tailor every rep and set to your physiology.

### 📊 High-Fidelity Dashboards
*   **3D Visualizations**: Immersive weather and health effects using **Three.js** and **React Three Fiber**.
*   **Real-time Analytics**: Beautiful, interactive charts powered by **Recharts** and **Framer Motion**.

### 💬 Intelligent Feedback System
*   **Sentiment Analysis**: Sophisticated processing of user feedback to categorize and prioritize improvements.
*   **AI Response Drafting**: Automated, empathetic support responses generated by LLMs to ensure high user satisfaction.

## 🛠️ Technology Stack

### Frontend
- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS 4.0
- **Animations**: Framer Motion
- **3D Rendering**: Three.js, @react-three/fiber, @react-three/drei
- **Visuals**: Recharts

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB (Mongoose)
- **AI Core**: OpenAI SDK (GPT-4o mini)
- **Security**: Helmet, Express Rate Limit, BcryptJS

### Infrastructure & Tools
- **Authentication**: Firebase Auth
- **File Storage**: Multer (Local/Buffer)
- **Deployment**: Vercel (Frontend), Railway (Backend)
- **Scheduling**: Node-cron

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas account
- OpenAI API Key
- Firebase Project (Storage & Cloud Messaging optional)

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/ajith2001reddy/smart-life-companion.git
   cd smart-life-companion
   ```

2. **Backend Setup**
   ```bash
   cd backend
   npm install
   ```
   Create a `.env` file in the `backend` directory:
   ```env
   PORT=5000
   MONGO_URI=your_mongodb_uri
   OPENAI_API_KEY=your_openai_key
   JWT_SECRET=your_secret_key
   ```

3. **Frontend Setup**
   ```bash
   cd ../frontend
   npm install
   ```
   Create a `.env.local` file in the `frontend` directory:
   ```env
   NEXT_PUBLIC_API_URL=http://localhost:5000/api
   ```

### Running the Application

**Run Backend:**
```bash
cd backend
npm run dev
```

**Run Frontend:**
```bash
cd frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to experience the future of wellness.
